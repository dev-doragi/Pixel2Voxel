# Prototype verification — 0.1.0

- Scope: experimental G1/G2/G3 vertical slice, G0 is NOT complete. Built in Linux using Lua 5.4 shared library via ctypes. No Aseprite or dotnet executable available. No claim of tested GUI/installation or desktop golden hash parity.
- `python extension-tests/lua_runner.py extension-tests/run.lua`: 12 PASS including the local legacy benchmark reconstructed by Lua: 20×22×12, 5,124 voxels, 2,054 faces. See the [original test log](../extension-tests/results.txt). Running without the optional benchmark fixture exercises the 11 synthetic checks. The installable extension contains no benchmark art.
- `python scripts/package-extension.py <path>`: reproducible package with root manifest, generated bundled main.lua, README and LICENSE. Lua bundle loaded without syntax error; ZIP integrity passed. Bundling avoids plugin-specific module path resolution; source stays componentized.
- Prototype differences from masterplan: only RGB, manual refresh default; live optional, pinned frame; no alignment thumbnails or template, no reprojection loss metric; simple fixed per-face shading; center anchor fixed across frames, no exported ground-pivot metadata; renderer uses new fixed-point triangle coverage, legacy hashes unverified; default density 2 for easier inspection; English UI only; no separate camera/model pose (rotation output uses equivalent relative yaw); no full G0 spikes; timer polls for host source close and queues jobs. Surface limit retains volume but disables Bake. Input capture, Aseprite image creation and output commit are synchronous, while CPU generation/rendering yields; responsiveness not measured. UI uses native flow layout, not a custom docking panel. No 6-view→plain stack export due to directional colors.
- Runtime raw pixel format, transparency, layer order, selection, resize, event callbacks, source closure and output transaction are unverified in real host. Use manual checklist below. No unsupported formats or native external dependencies shipped.

## G0 / manual host checklist
1. Record Aseprite version, app.apiVersion, OS, display scaling, window mode. Install package and verify Edit > Pixel2Voxel. Open and close twice, disable/re-enable extension. Check no duplicate menu or callbacks.
2. Open synthetic RGB demo PNG. Extrude depth 4, render density 2. Front/Right/Top/ISO should show correct orientation; orbit, Shift/middle pan, wheel, Fit, resize 20 times. Edit original while window stays open. Test 100/200% UI scaling and single/multiple windows.
3. Use active to pin source; edit, Undo, Redo, switch documents, close source. Live unchecked should require Refresh when events work; checked should rebuild. No stale result after closing. Frame change requires Use active.
4. Bake current, 8 directions and turntable. Check separate documents, fixed canvas, frame tags/durations, transparent background, no source modifications. Save/reopen; compare front with original at 1x. Cancel during long bake, verify no partial output.
5. Create editable stack from Extrude. Verify layer order and empty slices, use active + Layer stack, edit and rebuild. Test a cel offset. Hidden/group/tilemap/partial opacity cases must follow README restrictions.
6. Open original benchmark RGB copy, choose Six views, default alignment. Expect 20×22×12 and 5124. Test invalid width, intermediate alpha, empty face, duplicate slot swap, flip/offset and cancel. Compare original before/after. Existing .NET tests require SDK specified by global.json.
7. If any step fails capture exact error and source sample; treat as blocker, do not call prototype release-ready.
