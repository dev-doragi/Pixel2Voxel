# Reconstruction Specification

## 직교 입력

- 정적 6×1 PNG: Front, Right, Back, Left, Top, Bottom 고정 순서
- 사용자가 각 면을 지정하는 개별 PNG 1~6장
- 선택된 이미지는 같은 캔버스 크기를 사용한다.
- Alpha 0은 빈 공간이며 Alpha 1~255는 점유 픽셀이다.
- Alpha 1~255의 RGBA는 면 색상에 그대로 보존하며 빈 면은 입력 오류다.

## 정규화

재구성 전에 원본 PNG는 비파괴 draft로 검사한다. Target Face별 변환은 `Horizontal/Vertical Flip → 정수 Offset → 원본 크기 캔버스 클리핑` 순서이며 정렬 변경만으로 기존 `VoxelDocument`를 교체하지 않는다. 차단 오류가 없고 사용자가 Apply를 선택했을 때만 아래 정규화와 재구성을 실행한다.

1. 각 면의 불투명 픽셀을 `FaceCoordinateTransforms`로 모델 축에 투영한다.
2. X, Y, Z별로 관측된 범위의 합집합을 구한다.
3. 각 축 최소값을 0으로 이동하고 `max - min + 1`로 크기를 구한다.
4. 관측되지 않은 축은 사용자가 지정한 양의 fallback 길이를 사용한다.

## Visual Hull

`IVoxelReconstructor.Reconstruct(OrthographicViewSet)`은 정확히 여섯 면을 가정하지 않는다. 각 후보 셀을 제공된 모든 뷰로 투영하고 모든 알파가 1 이상일 때만 점유시킨다.

- 각 점유 셀은 제공된 방향별 원본 RGBA를 별도로 보존한다.
- 제공된 방향의 원본 색상은 다른 방향 색상으로 덮어쓰지 않는다. 미관측 면만 아래의 결정적 평균색으로 초기화한다.
- 후보 공간 한도: 1,048,576셀
- 노출 표면 캐시 한도: 500,000면
- 표면 한도 초과 시 `VoxelDocument`는 유지하고 `VoxelMeshData`만 생성하지 않는다.

## 파생 렌더 데이터

`VoxelMeshData`는 이웃이 비어 있는 면만 포함한다. 면마다 정점 4개와 인덱스 6개를 독립적으로 가지며 모델 원본이나 프로젝트 저장 데이터가 아니다.

## 부분 면 입력

- 개별 PNG 가져오기는 서로 다른 1~6개 면을 허용한다.
- 선택한 면의 U/V가 관측하지 않는 모델 축은 사용자가 지정한 양의 길이를 사용한다.
- 관측된 축은 입력 실루엣 범위가 우선하며 fallback 길이를 무시한다.
- 입력이 없는 복셀 면은 해당 복셀에서 관측된 면 색상의 premultiplied RGBA 평균으로 초기화하며 이후 일반 페인트 도구로 수정할 수 있다.

## 애니메이션 프레임

- Aseprite JSON의 프레임 수와 각 index의 duration이 모든 선택 면에서 정확히 같아야 한다.
- trim 프레임은 원본 캔버스로 복원한 뒤 정적 면과 같은 좌표 변환·재구성 규칙을 적용한다.
- 각 프레임은 독립 `VoxelDocument`이며 Undo/Redo는 프로젝트 전체 편집 순서와 프레임 식별자를 함께 기록한다.

## 재투영 검증과 원본 마스크 수정

- 재구성된 occupied voxel은 샘플링과 동일한 `FaceCoordinateTransforms`로 각 원본 뷰에 재투영한다.
- 원본의 `alpha > 0` 점유와 재투영 점유가 다른 픽셀을 실루엣 충돌로 집계한다. 색상 차이만으로는 충돌이 아니다.
- 사용자는 변환된 원본 마스크 픽셀을 칠하거나 지울 수 있으며 수정된 불변 이미지 사본이 최종 재구성 입력이 된다.
